# 📈 Trading Academy

An interactive website that teaches trading step by step, from Day 0 to advanced level.
I built it for my own crypto and forex trading study.

🔗 **Live website:** https://ahmadkhan-ai-dev.github.io/trading-academy/

## ✨ Features

- **Course engine** — lessons day by day, phase by phase
- **Progress tracking** — the app remembers where you stopped
- **Trading Journal** — record backtest and demo trades
- **Circuit Breaker** — stops you after too many losses to protect your account

## 🛠️ Built With

- HTML, CSS, JavaScript
- Hosted on GitHub Pages
- Built with the help of Claude Code

## 🚀 How to Use

1. Open the live website link above
2. Start from Day 0
3. Log your practice trades in the Trading Journal
